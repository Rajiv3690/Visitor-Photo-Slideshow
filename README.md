# Visitor Photo Slideshow

## About
Visitor Photo Slideshow is a web application where visitors can submit their names and photos. Uploaded photos can be displayed in a slideshow on a computer or TV screen.

## Features
- Visitor name submission
- Photo uploads
- Photo slideshow display
- Support for returning visitors
- Admin functionality
- Photo and visitor management

## Technology Stack
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Project Setup

### 1. Clone the repository
```bash
git clone https://github.com/YOUR-USERNAME/Visitor-Photo-Slideshow.git
cd Visitor-Photo-Slideshow
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the application
```bash
python app.py
```

### 4. Open the application
Open the local address shown in the terminal in your web browser.

## Project Structure
- app.py: Main application
- templates/: HTML templates
- static/: Static assets and uploaded files
- requirements.txt: Python dependencies

## Privacy
Visitors should be informed that uploaded photos may be displayed publicly and consent should be obtained before uploading.
