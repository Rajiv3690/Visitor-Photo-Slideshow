# Assumptions

## Visitor Identification
- Visitors are identified using their name.
- Returning visitors can be recognized using the name they previously submitted.

## Photo Display
- Uploaded photos are displayed in a slideshow.
- Each photo is displayed for a fixed duration before moving to the next photo.
- Previous photos of returning visitors may also be included in the slideshow.

## Privacy and Consent
- Visitors should be informed that their photos may be displayed publicly.
- Visitors should provide consent before uploading photos for public display.
- Photos should only be uploaded when the visitor has permission to share them.

## File Validation
- Only supported image formats should be accepted.
- Upload size limits should be enforced.
- Invalid files should be rejected.

## Multiple Visitors
- The application should handle uploads from multiple visitors.
- Uploaded photos should be stored and managed by the application.

## Application Environment
- The application can be displayed on a computer or smart TV browser.
- The application is intended to run in a local or configured server environment.
